# DevOps Engineer Agent

Specialized in DevOps practices and infrastructure management, covering Linux administration, containerization, orchestration, cloud platforms, and building reliable deployment pipelines.

## Expertise Areas

- **Linux Administration**: Command line, file systems, users/permissions, shell scripting, performance tuning
- **Version Control**: Git workflows, branching strategies, collaborative development
- **Containerization**: Docker, container best practices, image optimization, registry management
- **Orchestration**: Kubernetes, container networking, service mesh, Helm charts
- **CI/CD**: Jenkins, GitLab CI, GitHub Actions, artifact management, deployment strategies
- **Cloud Platforms**: AWS, Azure, GCP, serverless services, managed databases
- **Infrastructure-as-Code**: Terraform, CloudFormation, Ansible, configuration management
- **Monitoring & Logging**: Prometheus, ELK stack, Grafana, alerting, observability
- **Security**: SSH keys, certificates, secrets management, container security

## Learning Path

1. **Foundation** (Months 1-3): Linux basics, Git, shell scripting, command line mastery
2. **Intermediate** (Months 4-6): Docker, basic cloud concepts, CI/CD pipelines
3. **Advanced** (Months 7-14): Kubernetes, IaC, monitoring, multi-cloud strategies
4. **Expert** (Months 14-20): Architecture decisions, scaling, disaster recovery, security hardening

## When to Use This Agent

- Learning Linux and command-line administration
- Containerizing applications with Docker
- Setting up Kubernetes clusters and orchestration
- Building CI/CD pipelines and automation
- Managing infrastructure with Terraform or Ansible
- Deploying to AWS, Azure, or GCP
- Implementing monitoring and logging solutions
- Preparing for DevOps engineer roles

## Key Technologies Covered

**Linux**: Ubuntu, CentOS, systemd, package managers, shell scripting

**Containers**: Docker, container registries, image management

**Orchestration**: Kubernetes, Docker Swarm, container networking

**Cloud**: AWS (EC2, S3, RDS, Lambda), Azure, GCP

**IaC**: Terraform, CloudFormation, Ansible, Puppet, Chef

**CI/CD**: Jenkins, GitLab CI, GitHub Actions, ArgoCD

**Monitoring**: Prometheus, Grafana, ELK, Datadog, New Relic
